# Установка

## Скачать и перенести

1. Скачайте DMG с [langflip.app](https://langflip.app).
2. Откройте образ двойным щелчком и перетащите **LangFlip** в папку «Программы».
3. Запустите приложение из «Программ» или через Spotlight (⌘ Space → «LangFlip»).

Значок появится в строке меню, справа вверху. Иконки в Dock у приложения нет — это нормально.

::: warning Текущая сборка пока не нотаризована
Приложение подписано сертификатом разработчика, но ещё не прошло нотаризацию Apple, поэтому при первом запуске macOS покажет предупреждение. Обход: щёлкните по значку приложения **правой кнопкой → «Открыть»** и подтвердите. Повторить нужно дважды — по одному разу на каждое окно. Дальше приложение запускается обычным способом.

Этот раздел исчезнет, когда сборка станет нотаризованной.
:::

## Разрешения

При первом запуске LangFlip попросит два доступа. Без них приложение установится и откроется, но исправлять ничего не сможет.

**Мониторинг ввода** (Input Monitoring) — чтобы видеть нажатия клавиш. Именно так приложение узнаёт, что вы набрали `ghbdtn`, и понимает, когда слово закончилось.

**Универсальный доступ** (Accessibility) — чтобы заменить набранное: стереть неверные символы и напечатать правильные.

Оба выдаются в «Системных настройках» → «Конфиденциальность и безопасность». LangFlip открывает нужный раздел сам — достаточно нажать кнопку в его окне настроек, на вкладке «Доступы». После выдачи разрешений приложение может потребовать перезапуска — macOS не всегда сообщает об этом явно.

**Микрофон** запрашивается отдельно и только если вы включите диктовку. Без диктовки доступ к микрофону не нужен.

## Выбор раскладок

Откройте настройки LangFlip (значок в строке меню → «Настройки…») и на вкладке **«Раскладки»** укажите, какую английскую и какую русскую раскладку вы используете. По умолчанию берутся «U.S.» и «Русская».

Это важно: автоматическое исправление при наборе работает для той пары, которую вы здесь укажете. Если у вас, скажем, «Русская — ПК» вместо обычной «Русской», выберите её, иначе символы будут пересчитываться по неверной карте.

## Запуск при входе

На вкладке «Основные» включите «Запускать при входе», чтобы приложение стартовало вместе с системой. Настройка использует штатный механизм macOS, поэтому отражается и в «Системных настройках» → «Общие» → «Объекты входа».

## Удаление

1. Выйдите из приложения через меню в строке меню.
2. Удалите `LangFlip.app` из «Программ».
3. Если хотите стереть настройки, статистику и скачанную речевую модель, выполните в Терминале:

```bash
defaults delete io.langflip.LangFlip
rm -rf ~/Library/Application\ Support/LangFlip
```

Разрешения снимаются отдельно, в «Системных настройках» → «Конфиденциальность и безопасность».
