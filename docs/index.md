# LangFlip

LangFlip исправляет текст, набранный не в той раскладке, и превращает речь в текст — всё на самом Mac, без интернета и учётных записей.

Приложение живёт в строке меню и не занимает места в Dock. Пока вы печатаете, оно замечает слова вроде `ghbdtn` и меняет их на «привет»; если нужно исправить что-то вручную — двойное нажатие ⌘. Отдельно есть диктовка: удерживаете ⌘, говорите, отпускаете — текст появляется в том поле, где стоит курсор.

## Требования

| Что | Значение |
| --- | --- |
| Система | macOS 14 Sonoma и новее |
| Процессор | Apple Silicon или Intel; диктовка заметно быстрее на Apple Silicon |
| Место на диске | 15 МБ приложение, ещё 626 МБ если включить диктовку |
| Разрешения | Мониторинг ввода и Универсальный доступ |
| Раскладки | Русская и английская, добавленные в системных настройках |

## Что LangFlip не делает

- Не отправляет наружу ни набранный текст, ни записанный звук — [почему в это можно верить](/privacy).
- Не работает в защищённых полях ввода: пароли и подобные поля исключены намеренно.
- Не переключает раскладку сам по себе, без исправления слова, — для этого есть системные средства.
- Не требует регистрации, подписки и не показывает рекламу.
