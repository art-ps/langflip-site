# LangFlip Landing — дизайн-спецификация

## Цель

Создать современный русскоязычный одностраничный лендинг бесплатного приложения LangFlip для macOS. Сайт должен за несколько секунд показать пользу приложения и дать прямую ссылку на скачивание актуального `LangFlip-0.2.1.dmg`.

Сайт публикуется как полностью статический проект на GitHub Pages. Установщик хранится среди статических файлов сайта, поэтому скачивание не зависит от наличия GitHub Release.

## Аудитория и основное сообщение

Основная аудитория — пользователи macOS, которые печатают на русском и английском и иногда вводят слово в неправильной раскладке.

Главное сообщение: «LangFlip исправляет неверную раскладку прямо во время печати и позволяет диктовать текст в любое активное окно — локально и бесплатно».

## Визуальное направление

Концепция «До / после»: ключевой визуальный образ — преобразование `ghbdtn → привет`. Светлый фон, мягкие сине-фиолетовые градиенты, крупная типографика, скруглённые карточки и элементы, напоминающие клавиши macOS.

Клавиша `⌘` используется как повторяющийся мотив. Небольшая анимация в первом экране поочерёдно показывает ошибочный ввод, нажатие `⌘ ⌘` и исправленное слово. Анимация не должна мешать чтению и отключается при системной настройке уменьшения движения.

Реальная иконка LangFlip используется в навигации и карточке продукта. Модельные иллюстрации и тяжёлые изображения не нужны.

### Навигация

- Иконка и название LangFlip.
- Якорные ссылки «Возможности», «Приватность», «Установка».
- Компактная кнопка «Скачать».

### Первый экран

- Метка «Бесплатно для macOS».
- Заголовок о мгновенном исправлении раскладки.
- Короткое пояснение об автоматическом исправлении и ручном переключении двойным нажатием `⌘`.
- Демонстрация `ghbdtn → привет`.
- Основная кнопка «Скачать LangFlip 0.2.1».
- Подпись: macOS 14+, DMG, около 4,3 МБ.

### Возможности

Три основные карточки:

1. Автоматическое исправление слов, набранных в неправильной русской или английской раскладке.
2. Ручное преобразование последнего слова двойным нажатием `⌘` с переключением раскладки и возможностью отмены через `⌥⌘Z`.
3. Диктовка в любое активное текстовое поле: удерживать `⌘`, говорить и отпустить для завершения. Распознавание выполняется на устройстве через whisper.cpp; функция включается по желанию и требует однократной загрузки речевой модели размером около 1,5 ГБ.

### Приватность

- Исправление и распознавание речи работают локально на Mac.
- Нажатия клавиш и полный текст полей не сохраняются.
- Нет аналитики, облачного API и отправки текста на сервер.
- Защищённые поля исключаются из обработки.

### Как начать

1. Скачать и открыть DMG, перетащить LangFlip в Applications.
2. При первом запуске открыть приложение через контекстное меню «Открыть», так как текущая сборка имеет developer-подпись и не нотарифицирована Apple.
3. Выдать разрешения Input Monitoring и Accessibility; доступ к микрофону нужен только для диктовки.
4. Выбрать русскую и английскую раскладки и при желании загрузить речевую модель.
